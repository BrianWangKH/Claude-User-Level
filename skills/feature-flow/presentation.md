# Presentation

Visuals, animation, feel, sound. Presentation only gets state through the logic layer's events; no decisions are made here.

1. Implement incrementally: one visible step at a time, each checkable in the editor or app. Tell the user how to look at each step.
2. Pure calculations in it (bounds, conversions, choices) go into functions with tests; "test decisions and numbers, not pixels".
3. At the end run `/code-review` medium.
4. Follow "Wrap up" in `SKILL.md`; the PR description lists the manual verification steps.
